# 操作步骤

按顺序一步步来，每步验证通过再进下一步。开始前先按根目录 `README.md` 的“首次配置”创建 `app_config.h`。

---

## 步骤 0 · 编译下载固件

1. 用 Keil MDK5 打开 `Project/IR_Gateway.uvprojx`（已配好全部源文件与编译选项）。
2. 确认宏定义含 `STM32F10X_MD, USE_STDPERIPH_DRIVER`、勾选 **Use MicroLIB**（详见 `Firmware/README.md`）。
3. 编译 0 错误 → ST-Link 下载。
4. 接好调试串口（PA2→USB-TTL RX），串口助手 **115200 8N1**。
5. 复位，应看到：
   ```
   ==== STM32 IR Gateway (bemfa TCP) ====
   clk=72000000Hz, connecting WiFi...
   [store] restored 0 IR slots
   ```
   板载灯（PC13）闪 3 下。**看到这个就说明工程跑起来了。**

---

## 步骤 1 · 里程碑 A：点灯自测（先不接红外）

用调试串口（PA3）或 ESP 发命令，行尾要有回车换行：

```
LED_ON      -> 灯亮，回 "OK LED_ON"
LED_OFF     -> 灯灭
LED_TOGGLE  -> 翻转
HELP        -> 打印命令表
```

> 只接了 PA2 看日志、没接 PA3 时，可先用 ESP 发命令测（见步骤 2）。

---

## 步骤 2 · 里程碑 A+：确认 ESP-01S 通路

1. 按接线文档接好 ESP-01S（VCC 3.3V、去耦电容、共地、TX/RX 交叉、RST 经 10kΩ 上拉并接 PB0）。
2. 手机连上 ESP，发送 `LED_ON` / `LED_OFF`。
3. 灯响应、调试串口同步打印 `OK LED_ON` → **手机→ESP→STM32 链路通了**。

排查：没反应先确认 ESP 用的是**出厂 AT 固件**、OLED 已走到 `WiFi:OK Net:OK`；再检查 ESP 供电、TX/RX 是否交叉、波特率 115200。

---

## 步骤 3 · 里程碑 B：测 1838B 接收（学习）

1. 接好 1838B（VCC 3.3V、OUT→PA0、共地）。
2. 发送 `LEARN 5`（学到测试槽 5），串口回：
   ```
   OK learning slot 5, press remote
   ```
3. 把**空调原装遥控**对准 1838B，按一下（比如“开机”），距离 3~5cm。
4. 收到一帧后串口回：
   ```
   OK learned slot 5, 227 edges (saved)
   ```
   段数（edges）一般几十到几百，空调整帧偏长，**正常**。`(saved)` 表示已经写入内部 Flash，掉电不丢。
5. 发 `DUMP` 可打印这帧的原始时序（微秒），确认数据合理、可复现：
   同一个键按两次，段数和数值应大致一致。

排查：一直没反应 → 检查 PA0 接线、1838B 供电、遥控有没有电、是否对准。

---

## 步骤 4 · 里程碑 C：测 38kHz 发射

1. 接好发射电路（PA6→1k→S8050 基极，红外 LED 经 100Ω 接 5V）。
2. 先验证载波发得出去：手机摄像头对准红外 LED，
   发送 `SEND 5`（回放刚学的帧）——摄像头里应看到 LED **闪烁的紫白光**
   （人眼看不见，手机能看到）。看到就说明 38kHz + 驱动电路 OK。

> 没有可回放的帧时，也可临时在代码里调用 `ir_tx_carrier(1)` 常开载波来测。

---

## 步骤 5 · 里程碑 D：学一条并回放到空调

1. `LEARN 0`  → 对着 1838B 按空调遥控“**开机**”键 → 回 learned。
2. 把红外 LED **对准空调**，发送 `POWER_ON`（= 回放槽 0）。
3. 空调响应（开机/关机）→ **整条链路打通！**

建议先学“开机/关机”或某个固定状态（制冷 26℃ 自动风）。
空调发的是整帧状态，学一个固定状态最稳。

当前实际映射（2026-08-03 已验证）：

| 先学 | 再用命令回放 |
|------|------------|
| `LEARN 0` 开机 | `SEND 0` |
| `LEARN 1` 关机 | `SEND 1` |
| `LEARN 2` 制冷26 | `SEND 2` |
| `LEARN 3` 制冷23 | `SEND 3` |
| `LEARN 4` 屏显切换 | `SEND 4` |
| `LEARN 5` ECO 模式 | `SEND 5` |

---

## 步骤 6 · 里程碑 E：手机全流程控制

手机 App/网页 → ESP-01S → 发送 `SEND 0~5` 等命令 → 空调动作。
到这里最小可用系统就完成了。

现在学习数据会自动保存到内部 Flash。可按这个顺序验证持久化：`LEARN 0` → 断电重上电 → `STATUS` 看 `SLOTS` 是否包含 `0` → 直接发 `SEND 0`。

---

## 一页速查

```
上电看日志  -> ==== STM32 IR Gateway (bemfa TCP) ====
点灯        -> LED_ON / LED_OFF
学习        -> LEARN 0  然后按遥控
回放        -> SEND 0
看时序      -> DUMP
看状态      -> STATUS
清槽        -> CLEAR 0
帮助        -> HELP
```
