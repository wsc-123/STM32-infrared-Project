# 注意事项

分“硬件/接线”“电源”“固件/调试”“红外特性”四类。带 ⚠️ 的是最容易烧板子或
排查半天的坑。

---

## 一、电源（最危险）

- ⚠️ **ESP-01S 只能 3.3V，绝不能 5V**，5V 会烧模块。
- ⚠️ ESP-01S 供电电流要够：至少 300mA，最好 500mA+。电流不足会
  **反复复位**（日志里 ESP 不停重启、Wi-Fi 断连）。
- ⚠️ 电解电容**别接反**：长脚正、短脚/白条侧负。接反可能鼓包甚至爆。
- 100uF/220uF 电解 + 104 陶瓷并在 ESP 的 VCC/GND，且**尽量贴近模块**。
- 红外那一路用 5V，STM32/ESP 逻辑是 3.3V，**分清楚哪路是几伏**。

---

## 二、接线

- ⚠️ **所有 GND 必须共地**：STM32、ESP、1838B、面包板电源、5V红外路。
  不共地 = 玄学故障（时好时坏、收发失败）的头号原因。
- ⚠️ 串口 **TX/RX 交叉**：STM32 TX(PA9) → ESP RX，STM32 RX(PA10) → ESP TX。接反收不到。
- ⚠️ **1838B 输出别直接 5V 灌进 PA0**：PA0 非 5V 容忍。用 3.3V 供电优先，
  这样 OUT 也是 3.3V 逻辑。
- ⚠️ 红外 LED **不要用 STM32 GPIO 直接驱动**，务必经 S8050。GPIO 电流不够且伤芯片。
- S8050 是 **NPN**，别拿成 S8550(PNP)，电路用法不同。
- 直插 TO-92 的 E/B/C 与贴片 J3Y(SOT-23) **脚序不同**，
  收到货用万用表/卖家图**再确认一次**再插。
- 限流电阻先 **100Ω**，跑通再谨慎试 68Ω/47Ω；一上来 47Ω 可能烧 LED/三极管。

---

## 三、固件 / 调试

- ⚠️ Keil 必须勾 **Use MicroLIB**，否则 `printf`(fputc) 不生效或卡死在 semihosting。
- 宏定义要有 `STM32F10X_MD` 和 `USE_STDPERIPH_DRIVER`，否则库编不过。
- ⚠️ **中断函数别重复定义**：`EXTI0_IRQHandler` 在 `bsp_ir_rx.c`，
  `USART1_IRQHandler` 在 `bsp_usart.c`。若模板 `stm32f10x_it.c` 里也有这两个空的，
  **删掉模板里的空函数**，否则 `multiply defined` 报错。
- 调试串口是 **USART2(PA2/PA3)**，ESP 是 **USART1(PA9/PA10)**，别接混。
- 命令**行尾要有回车/换行**（`\r` 或 `\n`），否则固件认为一行没结束、不执行。
- 串口参数统一 **115200 8N1**。
- 本工程用 DWT 做红外微秒计时，用 SysTick 提供 1ms 系统时基；`bsp_delay_init()` 必须在最前面调用。

## 四、红外特性（回放不灵时看这里）

- 空调遥控发的是**完整状态帧**（开关+模式+温度+风速一起），不是“温度+1”这种增量。
  所以学一个**固定状态**（如开机、制冷26自动风）最可靠。
- 学习/回放走的是**原始时序录制**，不解析协议。同一个键学到的段数
  两次应大致一致；差很多说明接收不稳（距离、角度、供电）。
- 载波固定 **38kHz、占空比 1/2**（2026-08-04 从 1/3 提高，增强发射功率）。少数品牌用 36k/40k，若能学到但空调不响应，
  可在 `bsp_ir_tx.c` 改 `IR_TIM_ARR` 试 36/40kHz。
- 学习时遥控离 1838B **3~5cm、对准**；太远太偏会丢边沿。
- 学习数据会自动保存到内部 Flash，掉电后自动恢复。内部 Flash 有擦写寿命，学习/清槽属于低频操作，正常家用无需担心；不要把 `LEARN` 当成高频压力测试反复刷。
- 发射时固件会**临时关闭接收**（避免自发自收），属正常。
- 单帧最多 600 段（`IR_RX_MAX_EDGES` / `IR_FRAME_MAX`）。极长的帧被截断时，
  可同步调大这两个宏（注意 RAM，F103C8 只有 20KB）。

## 五、上电前 / 后自检清单

上电前：

- [ ] ESP-01S VCC = 3.3V，且与 STM32 共地
- [ ] 电解电容极性正确，104 并在 VCC/GND
- [ ] 红外 LED 串了限流电阻（先 100Ω）
- [ ] S8050 的 E/B/C 已核对
- [ ] 1838B 先用 3.3V
- [ ] 串口 TX/RX 交叉无误

上电后：

- [ ] 调试串口打印 ready、板载灯闪 3 下
- [ ] ESP 不反复复位
- [ ] `LED_ON/OFF` 正常
- [ ] 按遥控时能 `LEARN` 到帧（段数合理）
- [ ] 摄像头能看到发射 LED 闪烁
- [ ] 红外电路不发烫

## 六、实战新增教训（2026-07-10 排错实录）

- ⚠️ **"3.3V 档没电、5V 档有电" ≠ 稳压器烧了，先查输入电源电压。**
  MB102 的 3.3V 稳压器需要输入 ≥4.5V 左右才能工作，输入偏低时 3.3V 档
  先失效、5V 档（近直通）还有电。换合格的 5V/1A 充电头即愈。
- ⚠️ **IWDG 初始化不要在使能前等 PVU/RVU 清零**：该同步回执要看门狗启动后
  才会完成，启动前死等 = 系统卡死在 `watchdog_init()`（Blue Pill 兼容芯片
  实测必现）。正确顺序：解锁→配置→喂狗→使能，见 `bsp_watchdog.c` 注释。
- ⚠️ **烧录别选 "Erase Full Chip"（全片擦除）**，会把 0x0800E000 的学习码
  一起抹掉。保持 Keil 默认的按扇区擦除即可。
- ESP-01S 的蓝灯**正常状态就是不亮**（上电闪一下、通信时闪烁），别把
  "灯不亮"当成"没供电"；反过来蓝灯长亮反而是启动异常（GPIO2 被拉低）。
- `WDG_TEST` 命令会故意锁死主循环以验证看门狗（约 4 秒后自动复位、OLED
  第一行显示 `WDG!` 指纹后自动恢复）。误发无害，学习码不丢。
- 红外发射不灵敏 = 发射电流不足。限流已从单颗 100Ω 改为 **3×100Ω 并联**
  （脉冲约 100mA），S8050 基极电阻从 1k 减小到 330~500Ω，实测灵敏度接近
  原装遥控器。
- 排错黄金法则：**一次只改一个变量**。当天"删看门狗 + 换供电"同时做，
  导致归因绕了一大圈；后来靠单变量回归 + OLED 打点（a~f 步进字母）才锁死
  真凶。改代码前先把打点/复位指纹这类"让系统自己交代"的手段用起来。
