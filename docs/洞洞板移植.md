# 洞洞板移植与分段验收

适用对象：当前已经在临时接线上实测可用的 STM32 红外空调网关。

目标不是重新设计电路，而是把现有接线固化，同时保留 Blue Pill、ESP-01S、OLED、1838B 的可拆换能力。红外学习码保存在 Blue Pill 内部 Flash，正常拔插和断电不会丢失。

## 一、移植原则

1. 所有模块优先插在排母上，不把模块直接焊死。
2. 元件放在洞洞板元件面；焊点和绝大多数导线放在焊接面。
3. 从焊接面看，左右方向与元件面相反。每焊一根线，都从元件面重新核对丝印。
4. 先焊排母和电源母线，空板检查通过后再插模块。
5. 每增加一个模块就上电验收一次，不一次性焊完整机。
6. 5V、3.3V、GND 使用固定颜色并在板边标记。建议红=5V、橙=3.3V、黑=GND，信号线使用其他颜色。
7. 本次最终供电采用 Blue Pill USB 单入口：实测 USB 后 `5V=5.15V`、`3.3V=3.32V`，3.3V 引脚给 ESP-01S、OLED 和 1838B 使用；ESP 旁必须加去耦电容并做联网满载复测。

## 二、最终电源结构

本次确定使用 **Blue Pill 的 USB 口作为唯一电源入口**。USB 进来的 VBUS 是 5V，Blue Pill 板载稳压器输出的 3.3V 分给低压模块：

```text
Blue Pill USB 口（5V）
  ├──> Blue Pill 5V 引脚
  ├──> 红外 LED 发射回路
  └──> Blue Pill 板载 3.3V 稳压器
         ├──> ESP-01S VCC
         ├──> OLED VCC
         └──> 1838B VCC

所有 GND 必须连成同一条公共地
```

具体落地时，从 Blue Pill 的 `5V`、`3.3V` 和 `GND` 排针分别引出三条母线。USB 插入 Blue Pill 后，5V 母线给红外发射回路，3.3V 母线给 ESP、OLED、1838B。ESP 电源脚旁并联电容，联网和红外连续控制测试通过后再封板。

调试时如果主板已经由 5V 母线供电，ST-Link 的 `3.3V` 只作电平参考，不再用它给整机供电；ST-Link GND 仍接公共 GND。

USB 供电必须使用额定 `5V/1A` 或更高的手机充电头和短而可靠的线；电脑键盘口、无源 USB Hub 或细长线可能在 ESP 发射峰值时压降。外部 5V 已接通时，不要再同时用另一只电源给 5V 母线供电。需要下载时可以接 SWDIO/SWCLK/GND，供电线只保留 USB 这一套；ST-Link 的 3.3V 不接。

## 三、推荐元件面布局

先不要焊，按下图在元件面干摆。USB 口、OLED、1838B 和红外 LED 都朝向板边，方便使用。

```text
                  洞洞板元件面（俯视）

  后侧
  ┌────────────────────────────────────────────┐
  │ 5V输入/稳压区       ESP-01S 排母           │
  │ 去耦电容靠近输入     天线伸出板边或下方留空 │
  │                                            │
  │       ┌──────────────────────────┐         │
  │       │ Blue Pill 两排排母       │  OLED   │
  │       │ USB口朝板边，模块可拔出   │  1x4排母│
  │       └──────────────────────────┘         │
  │                                            │
  │ SWD 1x4   UART2 1x3    1838B 1x3   IR LED │
  └────────────────────────────────────────────┘
  前侧 / 对着空调的一侧
```

布局要求：

- Blue Pill 两侧各使用一条排母。先把排母插到 Blue Pill 上定位，只点焊每条排母一个角，确认模块平直且能顺利拔插后再焊完。
- Blue Pill 的 USB 口必须能从板边插线；BOOT0/BOOT1 跳帽也要留出手指空间。
- ESP-01S 使用 `2x4` 排母，天线端尽量伸出洞洞板边缘。天线下方和前方约 10~15mm 不铺铜线、不放电源母线和大块金属。
- OLED 使用 `1x4` 排母，按模块丝印的 `GND/VCC/SCL/SDA` 顺序接线，不凭外形猜顺序。
- 1838B 使用 `1x3` 排母，按实物丝印 `VCC/GND/OUT` 接线；不同模块脚序可能不同。
- 红外 LED 放在朝空调的板边，可以略微抬高，最终再调整朝向。
- S8050、限流电阻和红外 LED 靠近放置，使约 100mA 的脉冲电流路径短而粗。
- SWD 和 UART2 调试排针放在板边，后续不拆机也能下载和看日志。

## 四、洞洞板连线表

### 4.1 电源与公共地

| 起点 | 终点 | 说明 |
|---|---|---|
| Blue Pill `5V` | 5V 母线 | USB VBUS 引出的系统 5V |
| Blue Pill `3.3V` | 3.3V 母线 | 板载稳压器输出，供 ESP/OLED/1838B |
| 5V 母线 | 3×100Ω 并联的一端 | 红外发射电源 |
| 3.3V 母线 | ESP `VCC` | 实测约 3.32V |
| 3.3V 母线 | OLED `VCC` | 3.3V |
| 3.3V 母线 | 1838B `VCC` | 3.3V |
| 公共 GND | 所有模块 GND、S8050 E | 必须全部导通 |

ESP 电源脚旁并联：

```text
ESP VCC -- 220~470uF 电解 -- ESP GND
        -- 100nF 陶瓷   -- ESP GND
```

电解电容长脚/正极接 3.3V，负极条纹侧接 GND。1838B 的 VCC/GND 旁再放一只 100nF 陶瓷电容。

如果联网时 OLED 反复重启、ESP 状态反复掉线，或 3.3V 明显低于空载的 3.32V，则先停止封板，恢复 MB102/独立 3.3V 供电方案；万用表的慢速读数可能看不到很短的电压跌落。

### 4.2 ESP-01S

| ESP-01S | 连接 |
|---|---|
| `TXD` | Blue Pill `PA10` |
| `RXD` | Blue Pill `PA9` |
| `RST` | Blue Pill `PB0`，并经 10kΩ 上拉到 3.3V |
| `EN/CH_PD` | 经 10kΩ 上拉到 3.3V |
| `GPIO0` | 经 10kΩ 上拉到 3.3V |
| `GPIO2` | 经 10kΩ 上拉到 3.3V |
| `VCC` | 独立稳定 3.3V |
| `GND` | 公共 GND |

`RST` 不得用导线直接短接 3.3V。PB0 正常时为开漏释放，固件需要复位 ESP 时会把 RST 拉低。

### 4.3 OLED、1838B 与调试接口

| 模块引脚 | Blue Pill |
|---|---|
| OLED `SCL` | `PB8` |
| OLED `SDA` | `PB9` |
| 1838B `OUT/S` | `PA0` |
| UART2 `DBG_TX` | `PA2` -> USB-TTL RX |
| UART2 `DBG_RX` | `PA3` <- USB-TTL TX，可选 |
| SWD `SWDIO` | `PA13` |
| SWD `SWCLK` | `PA14` |
| SWD `GND` | 公共 GND |

### 4.4 红外发射

当前实测有效版本：

```text
5V -> 3×100Ω 并联(约33Ω) -> 红外 LED 正极
红外 LED 负极 -> S8050 集电极 C
S8050 发射极 E -> GND
Blue Pill PA6 -> 330~500Ω -> S8050 基极 B
S8050 基极 B -> 10kΩ -> GND（推荐）
```

不要照旧原理图中的单一 `470Ω` 标注理解成 LED 限流电阻。PA6 基极电阻可以是 330~500Ω；LED 限流是三只 100Ω 并联。S8050 的 E/B/C 必须按手上器件资料或万用表确认，不能只凭常见脚序。

万用表确认方法：

- 红外 LED 用二极管档测，正向通常约 1.0~1.5V；红表笔接阳极、黑表笔接阴极时有读数，长脚一般是阳极，但仍以测量为准。
- S8050 是 NPN。二极管档中，基极对发射极、基极对集电极都应在同一方向出现约 0.55~0.8V 的压降；能分别对另外两脚导通的那一脚才是基极。发射极和集电极的先后仍以器件资料或三极管 hFE 档确认，不能只凭外观。
- 三只 100Ω 并联后等效约 33Ω；先单独测每只，再焊成并联，避免把焊点或其他回路一起算进去。

## 五、分阶段焊接和验收

### 阶段 0：保留可回退状态

- 临时接线整机上电，确认 OLED 最终显示 `WiFi:OK Net:OK`。
- App 分别执行 `SEND 0`、`SEND 1`，确认开机和关机仍有效。
- 拍一张当前接线全景和若干模块近照，移植期间不要先拆完所有旧线。

### 阶段 1：只焊排母

- 干摆 Blue Pill、ESP、OLED、1838B、SWD、UART2 的排母。
- 先点焊定位，确认模块方向、拔插空间和板边接口，再焊完所有排母脚。
- 暂时不插任何模块。

验收：相邻排母脚之间不应被焊锡连桥；万用表蜂鸣档逐排检查。

### 阶段 2：焊三条电源母线

- 焊 5V、3.3V、GND 三条母线，在板边各留一个测试点。
- 电源线和红外发射回路使用较粗导线；普通信号线可以较细。
- 先不把电源母线接到模块排母，只完成母线和电源输入/稳压部分。

断电验收：

| 表笔位置 | 正常结果 |
|---|---|
| 5V 与 GND | 不持续蜂鸣 |
| 3.3V 与 GND | 不持续蜂鸣；电容充电可能短响 |
| 5V 与 3.3V | 不持续蜂鸣 |
| 任意两个相邻无关排母脚 | 不导通 |
| 所有 GND 点之间 | 持续蜂鸣，接近 0Ω |

空板上电验收：

- 先不插 Blue Pill、ESP、OLED、1838B。
- 黑表笔接 GND，直流电压档测 5V 测试点，应约 5.0V。
- 测 3.3V 测试点，应约 3.3V。
- 若电压错误，立即断电，不插模块。

### 阶段 3：Blue Pill + OLED

- 断电后接通 Blue Pill 的 5V/GND、OLED 的 3.3V/GND/SCL/SDA。
- 插入 Blue Pill 和 OLED，暂不插 ESP、1838B。
- 上电应看到 Blue Pill 板载灯闪烁和 OLED 启动画面；联网状态报错属于此阶段正常现象。

### 阶段 4：ESP 联网链路

- 断电，焊接 ESP 的 3.3V/GND、PA9/PA10、RST/PB0 和四个 10kΩ 上拉连接。
- 插 ESP 前再次测 ESP 排母的 VCC-GND，确认约 3.3V；确认 VCC 与 GND 方向和模块丝印一致。
- 插入 ESP 上电，OLED 应在数秒内进入 `WiFi:OK Net:OK`。
- App 发送 `STATUS` 或 `LED_TOGGLE`，确认云端、串口和 STM32 链路正常。

### 阶段 5：1838B 接收

- 断电，接 1838B 的 3.3V/GND/OUT，插入模块。
- 不要立即覆盖六个已验证槽位。先用原装遥控器对准接收头，结合调试日志确认有红外边沿；需要试学习时选定允许覆盖的槽位后再发 `LEARN n`。

### 阶段 6：红外发射

- 断电，确认红外 LED 极性和 S8050 E/B/C，再焊 PA6 基极电阻、10k 下拉、S8050、LED 和三只并联的 100Ω。
- 首次上电先发 `IR_TEST`，用手机摄像头确认红外 LED 有紫白闪光。
- 再对准空调执行 `SEND 0` 和 `SEND 1`，确认发射距离和可靠性。
- 连续测试后触摸检查电阻、S8050 和稳压器，不应明显发烫。

## 六、每次焊完一根线的固定动作

1. 断电状态下从元件面读起点和终点丝印。
2. 翻到焊接面，记住左右已经镜像。
3. 焊完后轻拉导线，确认机械连接牢固。
4. 万用表蜂鸣档确认目标两点导通。
5. 测目标点与左右相邻焊点，确认没有误短路。
6. 用记号笔在打印接线表上划掉这一根线。

## 七、最终上电前总检查

- [ ] Blue Pill、ESP、OLED、1838B 的方向均按丝印确认。
- [ ] 5V 对 GND 不短路。
- [ ] 3.3V 对 GND 不短路。
- [ ] 5V 与 3.3V 不短路。
- [ ] ESP VCC 排母实测为 3.3V，不是 5V。
- [ ] ESP RST 经 10kΩ 上拉，且与 PB0 直连，没有直接短接 3.3V。
- [ ] ESP 天线区域没有母线或大块金属遮挡。
- [ ] OLED 和 1838B 均使用 3.3V。
- [ ] S8050 E/B/C 已按实物确认。
- [ ] 红外 LED 有限流电阻，极性正确。
- [ ] 所有 GND 点互相导通。
- [ ] BOOT0 保持为 0。
- [ ] 板底没有焊锡球、线头或可能碰壳短路的裸线。
- [ ] 外部供电时 USB 5V、ST-Link 3.3V 未与主供电并联。
