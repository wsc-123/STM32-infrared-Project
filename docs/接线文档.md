# 接线文档

芯片：STM32F103C8T6 最小系统板（Blue Pill），系统主频 72MHz。

本工程使用 USB 单入口供电，并分出两种电压：

- USB 的 5V：Blue Pill 的 `5V` 引脚和红外 LED 发射回路。
- Blue Pill 板载稳压器的 3.3V：ESP-01S、1838B、OLED；2026-08-07 实测空载约 `3.32V`。

所有模块必须共地。先按本文接线，不要先改代码引脚。

---

## 二、电源总线接法

本次洞洞板移植使用 Blue Pill 的 USB 口作为唯一电源入口，从排针引出 5V、3.3V 和 GND 三条母线：

```text
USB 5V -> Blue Pill 5V -> 5V轨 -> 红外 LED 发射回路
Blue Pill 3.3V -> 3.3V轨 -> ESP-01S、1838B、OLED VCC
GND  轨 -> STM32 GND、ESP GND、1838B GND、OLED GND、S8050 发射极、USB-TTL GND、ST-Link GND
```

关键规则：

- USB 充电头建议额定 `5V/1A` 或更高，线材尽量短；2026-08-07 实测 USB 供电时 `5V=5.15V`、`3.3V=3.32V`。
- ESP-01S 只能接 3.3V，不能接 5V。
- ESP-01S 的 VCC/GND 旁必须并联 `220~470uF` 电解和 `100nF` 陶瓷电容；联网和连续红外控制时观察是否掉线或重启。
- 如果 3.3V 带载后明显下降、OLED 重启或 ESP 反复掉线，再改用 MB102/独立 3.3V 稳压模块，不把两个 3.3V 输出并联。
- USB 供电时 ST-Link 只接 SWDIO、SWCLK、GND；不要接 ST-Link 的 3.3V，也不要再接另一只 5V 电源。
- 红外 LED 的 5V 只经过限流电阻、LED、S8050 到 GND，STM32 PA6 只通过 1k 电阻驱动基极。

ESP 去耦电容必须靠近 ESP-01S：

```text
ESP VCC(3.3V) --+---[100uF 或 220uF 电解，长脚接 VCC]---+-- ESP GND
                +---[104 陶瓷 0.1uF，无极性]------------+
```

## 三、烧录 / 调试器（ST-Link，SWD）

下载固件用 ST-Link 的 SWD 接口：

```text
ST-Link SWDIO -> STM32 PA13
ST-Link SWCLK -> STM32 PA14
ST-Link GND   -> 公共 GND
ST-Link 3.3V  -> 不接（整机由 Blue Pill USB 供电）
ST-Link NRST  -> STM32 NRST（可选）
```

Blue Pill 启动跳线：

```text
BOOT0 -> 0 / GND
BOOT1 -> 0 / GND（通常板上默认）
```

注意：

- PA13/PA14 是下载调试口，不要拿去接别的模块。
- USB 已给整机供电时，ST-Link 只接 SWDIO、SWCLK、GND；不要让 ST-Link 的 3.3V/5V 与板上电源并联。
- 下载后保持 BOOT0=0，从用户 Flash 正常启动。

## 四、ESP-01S（Wi-Fi，USART1）

本工程使用 ESP-01S 出厂 AT 固件，STM32 通过 USART1 发送 AT 指令并连接巴法云 TCP。

```text
ESP-01S TX       -> STM32 PA10 (USART1_RX)
ESP-01S RX       -> STM32 PA9  (USART1_TX)
ESP-01S VCC      -> 3.3V 稳定电源
ESP-01S GND      -> 公共 GND
ESP-01S EN/CH_PD -> 3.3V（建议 10k 上拉）
ESP-01S GPIO0    -> 3.3V（正常运行；拉低才是下载模式）
ESP-01S GPIO2    -> 3.3V 或模块默认上拉
ESP-01S RST      -> STM32 PB0，同时经 10kΩ 电阻上拉到 3.3V
```

串口说明：

- TX/RX 必须交叉：ESP TX 接 STM32 RX，ESP RX 接 STM32 TX。
- STM32 和 ESP 都是 3.3V 逻辑，PA9 直连 ESP RX 可以。
- ESP 波特率按固件使用 115200。

### ESP-01S RST 自动恢复接线

ESP-01S 的 `RST` 为低电平复位。最终接点同时连接 STM32 `PB0` 和一只 `10kΩ` 上拉电阻：

```text
ESP 所用的 3.3V
       │
      10kΩ
       │
       ├──────── ESP-01S RST
       │
       └──────── STM32 PB0

ESP-01S GND ──── STM32 GND（公共地）
```

接线步骤：

1. 完全断电。
2. 如果 `RST` 原来用杜邦线直接连接 `3.3V`，先拆掉这根直连线。
3. 将 `10kΩ` 电阻一端接 ESP 使用的 `3.3V`，另一端接 `RST`；电阻不分方向。
4. 用一根杜邦线将 STM32 `PB0` 直接连接到同一个 `RST` 接点。
5. 保持 STM32 与 ESP 共地，再上电测试。

不能把 `RST` 继续直接短接到 `3.3V` 后再接 PB0。固件复位时 PB0 会主动拉低，直接短接会造成 3.3V 对地冲突；`10kΩ` 电阻既能在 PB0 释放时保持 RST 为高电平，也允许 PB0 安全拉低。

固件把 PB0 配置为开漏输出：正常运行时释放，由 `10kΩ` 拉到 3.3V。2026-08-04 起上电先用 AT 探测（1 秒一次、最多 3 次），ESP 有响应就直接沿用当前状态联网、不再复位；全部无响应才拉低 RST 约 `200ms`，释放后等待 ESP 启动约 `2.5s`。在线后每 10 秒查询一次 WiFi/TCP 状态；每次进入联网错误状态把连续失败计数加 1，成功恢复在线后清零，连续失败达到 3 次后执行该硬复位流程。两次硬复位至少间隔 60 秒。

正常上电时 OLED 直接从 `WiFi:.. Net:..` 进到 `WiFi:OK Net:OK`，通常几秒内完成；`ESP reset...` 只在 ESP 对 AT 无响应触发硬复位时才出现。万用表通常看到 RST 稳定在约 3.3V；如果一直为 0V或ESP断电，ESP不会回应 AT 命令，约 10 秒内显示 `ESP:ERR Net:--`。

注意：RST 只是复位信号，不是电源开关。拔掉 ESP 的 3.3V 后，PB0 无法让它重新启动；固件会显示离线并持续重试，重新接回电源后才能自动恢复。2026-08-04 已实测拔电检测和恢复供电自动重连均正常。

巴法云网页可能比 OLED 晚几十秒到几分钟显示离线。OLED 是本地 `AT+CIPSTATUS` 主动探测；突然断电的 ESP 无法向服务器发送 TCP 关闭通知，巴法云需要等心跳/TCP 超时后再清理连接。这属于正常延迟，不影响 OLED 状态判断。

故障判断：

| 现象 | 重点检查 |
|------|----------|
| OLED 一直 `WiFi:...` | WiFi 名/密码、2.4GHz、ESP 供电 |
| OLED 显示 `ESP:ERR Net:--` | RST 是否一直为低、PB0/RST 接线、ESP 供电、TX/RX、115200 波特率 |
| OLED 显示 `WiFi:ERR Net:--` | WiFi 名/密码、2.4GHz、信号和路由器状态 |
| OLED 显示 `WiFi:OK Net:ERR` | 网络出口、巴法云服务器连接 |
| OLED 显示 `WiFi:OK Sub:ERR` | TCP 已通但订阅失败：巴法云私钥、主题名 |
| 巴法云订阅者离线 | 主题名/私钥、ESP 是否拿到 IP、TCP 是否连通 |

## 五、调试串口（USB-TTL，USART2）

调试串口只用于看日志，也可预留给本地发送命令。

```text
STM32 PA2 (USART2_TX) -> USB-TTL RX
STM32 PA3 (USART2_RX) -> USB-TTL TX（可选；只看日志可不接）
USB-TTL GND           -> 公共 GND
```

电脑串口助手参数：

```text
115200 baud, 8 data bits, no parity, 1 stop bit (115200 8N1)
```

上电应看到：

```text
==== STM32 IR Gateway (bemfa TCP) ====
clk=72000000Hz, connecting WiFi...
[store] restored N IR slots
```

注意：

- USB-TTL 必须选 3.3V TTL 电平，不要用 RS232 电平。
- 不要把 USB-TTL 的 5V 随便接到 3.3V 轨。
- 如果同时接 USB-TTL 和 ST-Link，两者 GND 都要接公共 GND。

## 六、红外接收 1838B（学习用，PA0）

1838B 用来接收原装空调遥控器的红外脉冲。

```text
1838B + / VCC -> 3.3V
1838B - / GND -> 公共 GND
1838B S / OUT -> STM32 PA0
```

注意：

- 1838B 模块脚位标识可能是 `S - +`，也可能是 `OUT GND VCC`，按你手上模块丝印为准。
- 固件把 PA0 配成上拉输入，并使用 EXTI0 双边沿中断。
- 1838B 输出通常低电平有效：空闲高，收到红外时拉低。
- 优先用 3.3V 供电。若某模块必须 5V 供电，OUT 可能也是 5V，不要直接进 PA0。

学习时距离：

```text
遥控器发射头 -> 1838B 接收头，约 3~5cm，对准
```

## 七、红外发射（S8050 低边开关 + 红外 LED，PA6）

STM32 不直接驱动红外 LED，而是用 PA6 输出 38kHz PWM，经过 S8050 放大电流。

**当前实际接法（2026-07-10 增强后，实测灵敏度接近原装遥控器）**，其中 5V 来自面包板供电模块的 5V 轨：

```text
面包板 5V 轨 -> 3×100Ω 并联(≈33Ω) -> 红外 LED 正极(长脚/Anode)
红外 LED 负极(短脚/Cathode) -> S8050 集电极 C
S8050 发射极 E -> 公共 GND
STM32 PA6 -> 330~500Ω -> S8050 基极 B
```

发射为 38kHz 脉冲，LED 脉冲电流约 100mA，在红外 LED 与 S8050 的安全区内。
首次搭建若求稳，可先用单颗 100Ω + 基极 1k 跑通，再按上面升级。

等效电流路径：

```text
5V -> 限流电阻 -> 红外 LED -> S8050 C-E -> GND
```

S8050 TO-92 直插常见脚序（平面/字面朝自己，引脚朝下）：

```text
左 = E 发射极    中 = B 基极    右 = C 集电极
```

但不同批次/封装可能不同，最终以卖家图或万用表确认。不要把 S8550(PNP) 当 S8050(NPN) 用。

可选增强：

```text
S8050 基极 B -> 10kΩ -> GND
```

这个下拉电阻可让上电复位期间三极管更稳地关闭，不接通常也能工作。

限流电阻建议：

| 电阻 | 用途 |
|------|------|
| 100Ω | 首次调试推荐，较安全（约 33mA，近距离可用但不灵敏） |
| 3×100Ω 并联 ≈33Ω | **当前采用**，约 100mA 脉冲，灵敏度接近原装遥控器 |
| 68Ω / 47Ω | 介于两者之间的过渡选择 |

手机摄像头通常能看到红外 LED 发射时的紫白闪光；人眼看不见属于正常。

## 八、OLED 显示屏（0.96 英寸 SSD1306，PB8/PB9）

使用 4 针 I2C OLED 模块：

```text
OLED VCC -> 3.3V
OLED GND -> 公共 GND
OLED SCL -> STM32 PB8
OLED SDA -> STM32 PB9
```

注意：

- 固件用软件 I2C，不占用硬件 I2C 外设。
- OLED 从机地址固定写 `0x78`，对应常见 7 位地址 `0x3C`。
- 如果模块用 5V 供电，SCL/SDA 上拉可能变成 5V，不建议这样接；统一用 3.3V。
- 若你买的是 7 针 SPI OLED，接法和驱动都不同，不能按本文接。

## 九、推荐接线顺序

按这个顺序接，方便定位问题：

1. 只接 STM32 + ST-Link，确认能下载。
2. 接 USB-TTL 到 USART2，看上电日志。
3. 接 ESP-01S 电源、启动脚和 USART1，确认基础 AT 通信正常。
4. 按上文连接 `PB0 -> RST` 和 `3.3V -> 10kΩ -> RST`，确认能自动复位并连接巴法云。
5. 接 OLED，看状态显示是否正常。
6. 接 1838B，发 `LEARN 5` 后按遥控，确认能学习到 edges。
7. 接 S8050 + 红外 LED 发射回路，发 `SEND 5`，用手机摄像头看红外 LED 是否闪。
8. 最后把红外 LED 对准空调，用 `POWER_ON` / `SEND 0` 验证控制效果。

不要一口气全接完再排查。先让每一段单独通过。

## 十、上电前万用表检查

上电前至少检查这些点：

- 3.3V 轨对 GND：约 3.3V。
- 5V 轨对 GND：约 5V。
- ESP VCC 对 GND：约 3.3V，不是 5V。
- ESP RST 不与 3.3V 直接短接，而是经 `10kΩ` 上拉；RST 与 STM32 PB0 直连。
- 1838B VCC 对 GND：约 3.3V。
- OLED VCC 对 GND：约 3.3V。
- STM32 GND、ESP GND、1838B GND、OLED GND、5V 电源 GND 之间导通。
- 红外 LED 回路没有短路；S8050 E 接 GND，C 接 LED 负极，B 通过 1k 接 PA6。

上电后检查：

- PC13 闪 3 下。
- 串口打印启动日志。
- OLED 第 2 行从 `WiFi:...` 逐步到 `WiFi:OK Net:OK`。
- 巴法云 TCP 设备页订阅者从离线变在线。

## 十一、快速故障表

| 现象 | 优先检查 |
|------|----------|
| 板子没反应 | 3.3V/GND、BOOT0 是否为 0、固件是否下载成功 |
| 串口无日志 | PA2->USB-TTL RX、GND、115200 8N1、USB-TTL 电平 |
| ESP 反复重启 | 3.3V 电源电流、ESP 旁路电容、EN/RST |
| `ESP:ERR Net:--` | RST 是否约 3.3V、PB0/RST 是否短路、TX/RX、共地、AT 固件波特率 |
| 巴法云显示离线 | WiFi 名/密码、私钥、主题名、ESP TX/RX |
| `LEARN` 没有 edges | 1838B VCC/GND/OUT、遥控距离、PA0 接线 |
| 摄像头看不到红外亮 | PA6、1k 基极电阻、S8050 脚序、LED 极性、100Ω 限流 |
| 学得到但空调不响应 | LED 对准、发射电流、学习距离、重新学习固定状态 |
