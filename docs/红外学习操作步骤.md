# 红外学习操作步骤

> **2026-08-03 状态确认：学习已全部完成并验证。** 六个槽位学自原装遥控器、
> 回放实测有效，日常直接用手机 App 六个按钮即可。本文档保留作为"重学/新增
> 码"时的操作手册。美的模拟码路线已废弃并从 App 移除，请勿再使用。当前实际槽位表见第 5 节。

这份文档只讲“怎么学习空调遥控器的红外码”。1838B 已接到 STM32 `PA0`，六个槽位已有有效数据；只有需要覆盖某个槽位时才执行 `LEARN n`。

正常上电应看到 `WiFi:OK Net:OK`。发送 `STATUS` 可以确认网络状态和槽位；当前六槽应全部存在，不应再是 `slots:0`。

## 2. 学习红外必须具备的硬件

| 硬件 | 学习时是否必须 | 作用 |
|------|----------------|------|
| STM32F103C8T6 Blue Pill | 必须 | 运行主程序，保存红外码 |
| ESP-01S | 建议接好 | 从巴法云/手机接收命令 |
| 1838B 红外接收头 | 必须 | 接收原装遥控器发出的红外码 |
| 空调原装遥控器 | 必须 | 提供要学习的红外码 |
| OLED | 非必须但建议 | 看当前联网和学习结果 |
| 红外 LED + S8050 发射电路 | 学习时不必须，回放时必须 | 学完以后发给空调 |
| 100uF 电解电容 | 建议 | 给 ESP-01S/电源轨做缓冲，减少重启 |

学习过程本身只需要“1838B 接收 + 原装遥控器”。红外 LED 是回放时才用的。

## 3. 1838B 接线

当前已验证的 1838B 接线如下；重接或排错时按此核对：

| 1838B 引脚 | 接到哪里 | 说明 |
|------------|----------|------|
| VCC / + | 3.3V 正极 | 建议接 3.3V，不要接 5V |
| GND / - | 公共 GND | 和 STM32、ESP、电源模块的 GND 连在一起 |
| OUT / S | STM32 `PA0` | 程序用 EXTI0 捕获红外脉冲 |

注意事项：

- 不同 1838B 模块引脚顺序可能不同，按模块丝印接，不要只按图片猜。
- 所有 GND 要共地：STM32 GND、ESP GND、1838B GND、面包板供电模块负极必须连在一起。
- 你的面包板供电模块颜色可能反着，按模块 `+` / `-` 标识和万用表确认，不按红蓝颜色判断。
- 1838B 的接收窗口要朝向遥控器，学习时距离先放在 3~5cm。

## 4. 命令发送位置

有两种方式，任选一种：

| 方式 | 怎么发 | 说明 |
|------|--------|------|
| 巴法云/手机 | 给主题 `infrared` 发送命令 | 推荐，验证最终手机控制链路 |
| 调试串口 | USB-TTL TX 接 STM32 `PA3`，115200 8N1 | 本地调试更直观，完整 `DUMP` 只在调试串口看 |

命令要一行一条。串口发送时行尾带回车或换行。

## 5. 槽位规划

程序一共有 6 个学习槽：0~5。**下表是 2026-07-10 实际学习并验证通过的内容**（App 六个按钮与之一一对应）：

| 槽位 | 已学内容 | 回放命令 | edges |
|------|----------|----------|-------|
| 0 | 开机 | `SEND 0`（App"开机"）| 299 |
| 1 | 关机 | `SEND 1`（App"关机"）| 199 |
| 2 | 制冷 26 度 | `SEND 2`（App"制冷 26°"）| 299 |
| 3 | 制冷 23 度 | `SEND 3`（App"制冷 23°"）| 299 |
| 4 | 屏显切换（发一次切换一次）| `SEND 4`（App"屏显 开/关"）| 199 |

空调遥控通常不是只发“温度 +1”这种小命令，而是发一整帧状态。所以要控制哪些状态，就分别学习哪些状态。

## 6. 正式学习一条红外码

下面用槽 0 学“开机”为例。

1. 确认 1838B 已接好：`VCC -> 3.3V`，`GND -> 公共 GND`，`OUT/S -> PA0`。
2. 把空调原装遥控器对准 1838B，先不要按。
3. 手机/巴法云发送：
   ```
   LEARN 0
   ```
4. 正常会返回：
   ```
   OK learning slot 0, press remote
   ```
5. 看到上面提示后，短按一次遥控器的“开机”键，不要长按。
6. 学习成功会返回类似：
   ```
   OK learned slot 0, 227 edges (saved)
   ```
7. 其中 `227 edges` 是捕获到的脉冲段数，不同空调会不同；几十到几百都可能正常。
8. `(saved)` 表示已经写入 STM32 内部 Flash，断电后不会丢。

如果没有任何返回，不要先怀疑程序，优先检查 1838B 的 VCC/GND/OUT、PA0 接线、遥控器电池、遥控器是否对准接收头。

---

## 7. 验证是否真的保存成功

学习成功后发：

```
STATUS
```

如果学的是槽 0，应该看到类似：

```
NET ONLINE IP 192.168.31.27 SLOTS 0-----
```

然后可以断电重上电，再发一次 `STATUS`。如果还是 `SLOTS 0-----`，说明 Flash 保存和上电恢复都正常。

OLED 上的 `slots:N` 是上电时恢复了多少个槽位。刚学完以后，以 `STATUS` 返回的 `SLOTS` 为准。

---

## 8. 回放测试

学习成功后，把红外 LED 对准空调，发送：

```
POWER_ON
```

或者直接发送：

```
SEND 0
```

正常会返回类似：

```
OK sent POWER_ON (227 edges)
```

如果空调响应，说明“接收学习 -> 保存 -> 回放发射 -> 空调接收”整条链路通了。

如果空调没响应，但返回了 `OK sent`：

1. 用手机摄像头对准红外 LED，看发送时有没有紫白色闪光。
2. 检查红外 LED 极性，长脚/正极应通过限流电阻接 5V 正极。
3. 检查 S8050 引脚方向，发射极接公共 GND，集电极接红外 LED 负极。
4. 检查 5V 发射电路和 STM32/ESP/1838B 是否共地。
5. 把红外 LED 靠近空调接收窗，距离先控制在 10~30cm 内测试。

## 9. 学错了怎么重学

直接对同一个槽再发一次 `LEARN`，新学到的码会覆盖旧码。

例如重学槽 0：

```
LEARN 0
```

然后重新按一次原装遥控器。

如果想清空某个槽：

```
CLEAR 0
```

清空后发 `STATUS`，槽位 0 会从 `0-----` 变回 `------` 中对应的 `-`。

## 10. 常见问题

| 现象 | 优先检查 |
|------|----------|
| `slots:0` | 还没学过任何码，这是正常的 |
| 发 `LEARN 0` 后一直没 learned | 1838B 供电、GND、OUT 到 PA0、遥控器是否对准 |
| 学习成功但断电后没了 | 看返回是不是 `(saved)`，再发 `STATUS` 确认 |
| `SEND 0` 返回 empty | 槽 0 还没学成功，先 `LEARN 0` |
| 手机能发命令但没学习反应 | ESP 链路正常，问题多半在 1838B 接线或遥控器方向 |
| `DUMP` 没有完整数字 | 完整时序只从调试串口打印，巴法云不会回传全部时序 |
| 同一个键每次 edges 差很多 | 遥控器太远/太近、角度不对、强光干扰，调整到 3~5cm 再学 |
| 空调不响应但手机能看到 LED 闪 | 红外 LED 没对准空调、距离太远、学习的不是目标状态，重新学习 |

---

## 11. 一页速查

```
确认联网      -> STATUS
开始学习槽0   -> LEARN 0
按遥控器      -> 短按一次原装遥控器按键
确认保存      -> OK learned slot 0, xxx edges (saved)
看槽位        -> STATUS，看 SLOTS 0-----
回放槽0       -> SEND 0
命名回放      -> POWER_ON
清空槽0       -> CLEAR 0
调试时序      -> DUMP，只看调试串口完整输出
```

记住顺序：先 `LEARN 槽位`，看到提示后按遥控器，看到 `(saved)` 后再 `SEND 槽位` 回放。
